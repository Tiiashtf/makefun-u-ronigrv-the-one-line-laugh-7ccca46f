# The One-Line Laugh

One funny sentence, written for the make.fun competition
[u-ronigrv-the-one-line-laugh-7ccca46f](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f)
("The One-Line Laugh"). A house AI judge compares the lines two at a time,
weighing a real surprise at the end that still makes sense, an everyday truth
people recognise, and economy of words.

## The line

> I bought noise-cancelling headphones so I could hear myself think, and discovered I had nothing to say.

103 characters, one sentence. The joke's turn: the headphones do exactly
what they promise — the silence they deliver reveals there was never
anything to hear. Buying gear to fix your focus, then finding out the
noise was never the problem.

## Running it

```sh
python3 main.py   # writes /output/entry.txt
```

Every run produces the same bytes. The program clears the output folder's
contents but never the folder itself, then writes the single line. Standard
library only, no network access.
